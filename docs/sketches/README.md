## Что решено эскизами сверх PRD

- Фильтры на ПК применяются сразу, на телефоне — кнопкой «Показать [N] машин» в выезжающей панели.
- Кнопки «Оставить заявку» и «Забронировать» на телефоне закреплены у нижнего края экрана; на изображении они в конце страницы, потому что оно снято во всю высоту.
- В форме машины справа — список «Для публикации нужно» с отметками: те же поля, что проверяет ограничение публикации (PRD §6.2), видны до нажатия «Опубликовать».

## Состояния, которых нет на изображениях

На канве у экранов есть переключатели: каталог — загрузка со скелетонами, пусто, ошибка с повтором; карточка — под заказ и забронирована, кнопка брони неактивна; форма — ошибки у полей после неудачной публикации (ответ 422). По PRD §7 эти состояния обязательны для каждого списка и формы.
